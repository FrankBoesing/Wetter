# Wetter & Kalender

Eine kompakte, eigenständige Wetterseite und ein Feiertagskalender für Nordrhein-Westfalen.

## Anwendungen

- **[Wetter öffnen](https://frankboesing.github.io/Wetter/)**
- [Kalender öffnen](https://frankboesing.github.io/Wetter/Kalender.html)

Die Seiten sind statische HTML-Dateien und werden über **GitHub Pages** veröffentlicht.
